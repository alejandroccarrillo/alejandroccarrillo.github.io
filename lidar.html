A personal engine I build with a friend in pair programming, to go deep on modern C++, engine architecture, real-time rendering, networking and profiling.

Architecture

Arquitectura

The source code lives in a private repository, so this page describes the work and its architecture without screenshots or code.

El código está en un repositorio privado, así que esta página describe el trabajo y su arquitectura sin capturas ni código.

Rendering

Renderizado

  • Deferred pipeline with a G-buffer, shadow mapping and reflective shadow maps (RSM).
  • Real-time global illumination through a DDGI-style grid of probes, computed in compute shaders.
  • glTF asset loading with tinygltf.
  • Pipeline diferido con G-buffer, sombras y reflective shadow maps (RSM).
  • Iluminación global en tiempo real mediante una rejilla de probes tipo DDGI, calculada en compute shaders.
  • Carga de assets glTF con tinygltf.

Networking and tooling

Red y herramientas

  • Client-server architecture with GameNetworkingSockets, typed packets and a fixed-tick server at 20 Hz with a reusable buffer.
  • Network telemetry visible in the editor: ping, packets by type and bytes received.
  • One codebase that builds three executables: client, server and editor.
  • Tracy for profiling and spdlog for logging.
  • Arquitectura cliente-servidor con GameNetworkingSockets, paquetes tipados y un servidor a tick fijo de 20 Hz con buffer reutilizable.
  • Telemetría de red visible en el editor: ping, paquetes por tipo y bytes recibidos.
  • Un único codebase que genera tres ejecutables: cliente, servidor y editor.
  • Tracy para profiling y spdlog para logging.
